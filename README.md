# Remarkable — Launchpad UI

Responsive, animation-rich launchpad discovery interface built with React, Vite and GSAP.

## Local development
Install dependencies with `npm install`, then start with `npm run dev`.

## Build
Run `npm run build` to generate the production site in `dist`.

## Cloudflare Pages
Framework: Vite. Build command: `npm run build`. Output directory: `dist`. Root directory: `/`.
Connect the Pages production branch to `main` so new commits are deployed automatically.

## Phase 1 prototype
Includes token discovery cards, Trending/New/Watchlist tabs, search, watchlist toggles, responsive layout, GSAP entrance/orbit motion, ambient visuals, and a wallet modal placeholder. Token data is demo-only. Live market feeds, wallet authentication, token creation, trading, and backend persistence are not connected yet.
